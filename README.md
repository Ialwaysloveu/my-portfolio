# My Portfolio

Personal portfolio website built with HTML, CSS, and modern JavaScript.

## Configuration & Content Customization

To change the person's details, you only need to edit `data/person.js` or `data/person.json`.

Edit the following fields:
- `brand.logoText` and `brand.pageTitle`
- `hero` object (name, title, description, photoPath)
- `contact` (designFor, phone, email)
- `navLinks` list
- `expertise` list (titles, descriptions, icons)
- `works` list (projects and images)
- `about` (intro, quote, skills list, tools list)
- `testimonials` list
- `news` list
- `footer` (blurb, socialLinks, copyright)

Ensure any new images or documents referenced in `data/person.js` are placed in the `assets/person/` folder.
